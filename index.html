Testbed Management Dashboard

Self-service setups on demand, on any cloud

What I built

Designed a self-service Django, React and RabbitMQ platform that lets engineers spin up setups on demand on their chosen cloud platform (vCenter, AWS, Azure or GCP) and tear them down once used, eliminating manual setup and cutting setup time and infrastructure team dependency by 60%.

VMware by Broadcom

Regression Automation for Avi Load Balancer

Large regression suites kept green and trustworthy

What I built

Owned functional test coverage for VMware Avi Load Balancer (formerly NSX Advanced Load Balancer) features, running regular regression cycles to sustain a 100% pass rate, and validated deployments across all supported vSphere versions for release readiness.

Test execution was integrated into Jenkins CI, with scheduled sanity and regression runs and automatic sanity tests on every newly provisioned environment. I refactored the suites onto in-house framework libraries integrated with Pytest and Robot Framework, which made the test cases cleaner and easier to maintain.

When intermittent failures crept in, I traced their root causes, such as timing issues and environment dependencies, and redesigned the tests with robust synchronisation and isolated test data, so a failing run pointed to a real problem rather than noise.

Outcome

100%pass rate sustained across regular regression cycles
Flaky tests made stableunreliable suites turned into runs the team could trust
Problems found soonersanity tests run automatically on every new environment
